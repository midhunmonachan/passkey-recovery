# Passkey recovery

A deleted OpenAI passkey, an old Edge snapshot, and a successful sign-in.

**[Read the story and listen to the audio](https://openai-story.midhun.ca/)**

Midhun and Astra recovered a previously synced Microsoft Password Manager passkey after password cleanup removed it from connected devices. The separate recovery file had been erased with a returned laptop.

The successful attempt used historical Edge data, an offline startup, restricted provider connectivity, and the existing Password Manager PIN. It did not bypass authentication.

- [Technical findings](dist/notes/TECHNICAL-NOTES.md)
- [Timeline](dist/notes/TIMELINE.md)
- [Site source](dist/index.html)

This repository contains the publication only. It contains no recovered browser profiles, credentials, private emails, or account backups, and is not an automated recovery tool.
